Lab の最初の作品として、桜の花びらが舞う小さな絵を作った。最初は Canvas 2D で、花びらをスプライトにして転写する方式。1 フレーム 0.3 ms ほどで軽く、これはこれで十分だった。

それを WebGPU に移した。物理はコンピュートシェーダで回し、花びらはインスタンス描画した四角形の中で距離場として描く。画像は使わない。

## 形

最初は楕円に切れ込みを付けた形で、レンズのように見えた。次にハート形の距離場を試したら、今度はハートにしか見えない。結局、幅の断面関数で作る倒卵形に落ち着いた。肩が上寄りで、付け根はすっと細くなり、先端に浅い切れ込みがある。

Python で同じ関数を描いて断面を見ながら詰めた。シェーダを書き換えて確認するより、ずっと速い。

## 動き

面内でくるくる回すと紙吹雪になる。花びらは「ひらひら裏返る」動きの方が本物らしい。縦横 2 軸の傾きを別々に積分して、横幅と縦幅の伸縮で表した。

## つまずいたところ

- WGSL では `target` が予約語。
- 同じバッファを読み書き用と読み取り専用で同じバインドグループに束ねると、毎フレーム検証エラーになる。何も描かれないのに fps だけは出るので、しばらく気づかなかった。
- 幅が 0 になる区間で `|x| - 0 = 0` になり、中心線だけ半透明で残る。距離場に縦の境界を足して消した。
